# 控制台键盘操作与窄屏阅读

控制台沿用现有主题、字体、玻璃表面和减少运动偏好。维护页面支持键盘操作、完整安全字段详情及有界分页，方便在手机、较短视口或放大后的窗口中使用。

## 键盘与浮层

- `Ctrl+K` / `⌘K` 打开全局搜索。上下方向键选择候选，Enter 进入资源页面；输入法仍在组合文字时 Enter 不导航。搜索框通过候选列表说明当前选项。
- Escape 每次关闭最上层浮层。搜索可以打开在编辑窗口或移动导航上方，关闭后回到原窗口及可用的触发位置。Tab / Shift+Tab 留在当前模态内，背景暂时不可操作；最后一层关闭后恢复滚动。
- 菜单支持上下方向键、Home / End、Enter / Space。Tab 关闭菜单后继续到触发按钮的下一项，Shift+Tab 回到前一项。说明提示只负责自己的 Escape，不抢输入焦点。
- 原触发按钮已删除或停用时，焦点回到仍存在的上层窗口或主要内容。程序关闭下层窗口不会抢走上层搜索的焦点。
- 系统设置的四个标签支持左右方向键循环切换，以及 Home / End。Tab 只经过当前标签，再进入以该标签命名的内容面板。输入框、选择框、文本区和展开摘要都有可见焦点。

搜索会分别保留已读到的站点/账号、渠道及模型。某一类读取失败时显示该类的重试入口；当前搜索中的重试成功不会清掉其他已加载资源。关闭后清空查询并结束本轮请求，重开时按现有 API 的缓存与失效规则更新资源，页面已刷新的名称也能搜索。旧请求或已取消请求不会覆盖新一轮搜索。候选最多显示 14 条，超过时提示细化查询；服务器清单部分加载时显示覆盖数量及资源页入口。

手机导航可点击遮罩关闭并返回打开按钮；叠加搜索时，点击先关闭搜索并保留导航。已有操作提示的文本在弹窗打开时继续暴露给浏览器无障碍树，背景提示的关闭按钮仍隔离；实际屏幕阅读器播报需在具体设备验证。

## 分页与选择范围

| 列表 | 每页范围 | 选择/操作契约 |
| --- | --- | --- |
| 站点、账号 | 50 / 100 | “本页全选”只作用于当前页。已选择对象跨筛选和翻页保留，筛选外数量明确显示，清空选择不写入服务器 |
| 令牌 | 50 / 100 | 搜索回到第一页，删除末页后回到有效页 |
| 令牌权限中的模型、渠道 | 50 | 勾选跨页和搜索保留。“全选已加载”只添加当前已加载清单，原有未加载选择保留；必须点击保存才修改权限 |
| Key 健康 | 50 | 单把检测仍针对对应 Key；“检测当前筛选”按完整筛选取最多 20 把，翻页不会改变检测目标或触发检测 |

分页显示总量、当前范围和页数，可直接输入有效整数页码。无效输入有反馈；跳页的 Enter 不会提交外层编辑表单。筛选、页容量变化和删除后均保持有效页码。

Key 检测仍会实际调用模型，需要保留原有确认、停止后续检测、关闭时取消当前请求和未取得观察结果的语义，详见[Key 健康管理](key-health.md)。权限的 allow / deny 与软费用限额含义见[客户端接入](client-connection.md)及[费用说明](cost-semantics.md)。

## 完整详情与阅读

站点、渠道和令牌的操作列都提供文字“详情”入口。站点与渠道为可选操作预留固定列位，账号的桌面操作保持同一行；窄屏使用分行操作并保留编辑和删除。详情使用页面已经持有的字段，不执行探测、保存、配置恢复或密钥恢复。

- 站点详情包含完整名称、地址、平台、时区、状态、代理方式、账号入口、探测说明、签到方式及创建/更新时间。
- 渠道详情包含全部声明地址和协议、模型映射、路由优先级、有效优先级及成功率、成本倍率、RPM / 并发 / 每日软限额、Key 数量、冷却、同步归属和账号关联。
- 令牌详情只展示提示及安全元数据：模型、协议、渠道 allow / deny 范围、并发、费用软限额、用量、请求数和时间。提示缺失仍不回退到完整令牌。金额标注本地记账和未与上游对账的边界，未知状态保持未知。

详情按名值对展示，长名称、URL、模型和错误说明可以换行。URL 中的登录用户信息隐藏，非 HTTP 及格式无效的地址也先去除该部分再显示；自定义代理只显示是否已配置，详情不展开原始凭证或请求规则。窄屏列表将操作排列在名称下方，编辑和删除仍可到达。窗口标题允许折行，关闭按钮保持尺寸；短视口使用动态视口高度限制弹窗和搜索。

账号与签到列表的长错误只显示单行摘要，状态和原因合计最多两行；状态说明入口支持鼠标悬停、点击、触摸与键盘 Enter 查看全文。操作结果浮框中的恢复链接与按钮支持连续 Tab / Shift+Tab，越过边界后收起，Escape 返回入口；原有菜单的 Tab 关闭规则保持不变。列表与本页全选框使用 18px 控件、2px 边框、独立选中底色和键盘焦点环，高对比度模式使用原生复选框。

## 验证与适用范围

`scripts/ui_accessibility_smoke.py` 使用编译后的真实 React 页面、合成管理 API 和本地只读静态服务器验证键盘、分页、详情和资源预算。所有外部源阻止访问，不使用生产登录、数据库、上游账号或 WebDAV。截图为可见视口 JPEG，服务器、浏览器和上下文均在 finally 中关闭。

先运行 `console` 目录中的 `npm test`、`npm run typecheck` 和 `npm run build`，再执行 `python scripts/ui_accessibility_smoke.py --group all --output <外置证据目录>`。可用 `--group focus|search|lists|details|metrics` 或 `--case <用例名称>` 定位，`--root` 可指定已构建的项目目录。

400,000 字节的会话 gzip、45 个控制台资源请求，以及单路由 150,000 字节 gzip / 450,000 字节解压预算继续生效。共享图标合并为一个资源；页面代码在访问时动态导入，并在导航悬停或聚焦时预载，首屏不再集中预载全部页面。全部构建资产的 gzip 总和包含尚未加载的页面，不能代替实际会话的网络分母。

浏览器覆盖 320 / 390px、深浅主题、长文本、短视口及 720×450 的桌面 200% 等效布局；等效布局不代表实际操作系统或浏览器缩放。真实屏幕阅读器、手机软键盘和具体客户端仍需在部署环境体验确认。阶段证据、审查和本地整合记录见[验证记录](superpowers/plans/2026-11-22-ui-accessibility-verification.md)。
