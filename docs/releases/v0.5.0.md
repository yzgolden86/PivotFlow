# v0.5.0

本版完成 14 项已确认的改进主线，覆盖可靠结算、请求排障、统一模型路由、客户端接入、站点维护、配置恢复、控制台操作和可选请求缓存。

## 调用可靠性与排障

- 成功请求使用持久结算记录与幂等恢复，在队列饱和、存储短暂失败和重启恢复时保留结算依据。
- 完善带认证请求的同源重定向规则，以及流式和 Responses 会话的取消、半截流与重放边界。
- 每个请求有独立 ID，历史串联实际 Key／URL／协议尝试和最终结果，分别展示客户端成功率与上游尝试成功率。
- 新增运行健康观察，展示结算、日志、存储同步、恢复及长连接状态，帮助定位积压和降级。

## 统一模型与接入

- 新增模型路由工作台，解释统一组候选、实际权重、健康、粘性、令牌权限和尝试限制，并连接精确请求历史。
- 令牌模型清单使用统一映射后的名称；新建令牌未限制模型时，已映射变体不再作为独立模型散列展示。
- 完整成功同步或渠道模型替换后，按剩余渠道和权限引用核对并清理已确认消失的映射成员。同步失败、部分结果或暂时不可用不作为删除证据。
- 新增客户端接入引导，提供 Codex、Claude、Gemini 和 OpenAI Python 配置、权限范围内的模型选择及同源代理验证。

## 站点维护、导入与恢复

- 维护任务支持重复操作合并、同站点排队、共享请求预算与限流冷却、逐项进度及取消；未知结果提供核对入口。
- 配置恢复和渠道同步增加差异预览、冲突说明、固定快照、事务应用及重复确认保护。
- 新增浏览器账号辅助导入，支持有限存储读取和 All API Hub 2.0–4.0 明文账号子集，核对来源与目标，验证后按预览保存。
- 备份增加写后回读校验，完善恢复演练、凭证重加密、模型绑定和权限恢复说明。

## 费用与控制台

- 请求费用保存当时的价格来源、倍率和用量解释；区分已知零价、未定价、缺用量、部分估算与旧记录。
- 费用筛选贯穿日志、汇总和趋势，明确本地记录与上游账单的关系。
- 共享弹窗、菜单与全局搜索改进键盘焦点、Escape、失败恢复和窄屏操作；令牌、权限与 Key 列表采用有界分页，明确选择范围并保留跨页选择。

## 可选请求缓存

缓存默认关闭。启用后，客户端还需显式发送 `X-PivotFlow-Cache: use`；也支持 `refresh` 和 `bypass`。

首期只复用符合条件的原生 OpenAI Chat Completions／Anthropic Messages 非流式纯文本请求，要求显式 `temperature=0`，并按令牌和精确请求隔离。工具、会话、媒体、未知字段、协议转换与语义改写请求绕过缓存。

缓存受容量和有效期限制，命中仍检查权限、并发与结算准入。网关账目不重复累计上游用量和费用；复用响应正文中的原始 `usage` 保持原样，下游 SDK 应结合缓存响应头识别复用。

## 升级说明

- 升级前保存主数据库、每个实例的本地计费日志、凭证主密钥、启动配置和旧程序产物。新增历史及结算结构会在启动时迁移。
- JSON／WebDAV 配置恢复与渠道同步使用新版预览流程；直接调用旧无预览恢复接口的管理脚本需要调整，旧入口返回 `428 preview_required`。
- 无通用数据库降级流程。回退应恢复相互匹配的旧程序、数据库、计费日志和密钥，不能只替换旧二进制继续写入已升级的数据库。
- 缓存为进程内存数据，重启后清空；默认策略不会自动启用。

使用与升级细节见[模型路由](../model-routes.md)、[客户端接入](../client-connection.md)、[请求缓存](../request-cache.md)、[配置预览](../config-import.md)、[备份与恢复](../backup-recovery.md)和[升级与回退](../upgrade.md)。

## 本地验证

本版发布准备前，主目录已通过 35 个有测试后端包、5,181 个含子测试通过事件、317 项控制台测试、2 项登录页测试，以及 66 个缓存／共享界面／模型历史关联浏览器场景。双 TypeScript、Vite、静态检查和嵌入构建通过。

Windows 本地验证有 6 项跳过，涉及 POSIX 权限、未提供的 Gemini／Grok 语料和未配置的 MySQL 集成；未执行 Go race detector。发布工作流另行运行 Linux 后端、前端和构建门禁。真实部署的上游、客户端与存储拓扑仍需按升级文档验收。
