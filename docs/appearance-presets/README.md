# 外观预设（自定义 CSS 片段）

给 **设置 → 外观 → 自定义 CSS** 用的现成片段。复制整份内容粘进去，点一下别处（失焦提交）即生效 ——
不用重启，不用重新构建，也不写服务端。

> 变量与类名的权威定义在 `console/src/styles.css`。本文档只提供可直接粘贴的片段。
> 下面每个片段里用到的 `--*` 变量和类名都已在 `styles.css` 里核对过，不是猜的。

## 怎么用

1. 打开 **设置 → 外观**，找到「自定义 CSS」，勾上启用。
2. 把某个 `.css` 文件的**全部内容**粘进文本框。
3. 点一下输入框外面，立刻看到效果。
4. 想叠加多个效果：把几份内容**直接接在一起**贴进去即可（都在同一张样式表里）。
   ⚠️ 冲突项以**后面**的为准 —— 例如「硬朗直角」+「圆角拉满」放一起，后者赢。

## 出问题了怎么办（逃生开关）

自定义 CSS 写坏了，可能连设置页都点不进去。此时在地址栏加 `?plain=1`：

- `…/#/system?plain=1`
- 或 `…/?plain=1#/system`

命中后**完全不注入**自定义 CSS，进去把内容清掉，再正常访问即可。

## 注意事项

- **不要用 `@import`**：片段是追加到 `<head>` 末尾的，而 `@import` 必须写在样式表最前面，
  在这里会被浏览器忽略。
- **不要用 `@font-face` 拉外链字体**：同理会受限于插入位置与 CSP。字体请用设置里的字体选项，
  或自己装到系统里。
- **`!important` 只在确实压不过时才用**。本项目有些规则权重不低（例如
  `:root[data-theme="dark"] .data-panel` 是 0,2,1），滥用 `!important` 会让后续再调很难。
- **改 `--*` 令牌比逐元素写死更划算**：令牌一变，所有引用它的地方一起变，不会漏。
  反过来，本项目仍有不少规则把字号/圆角写成了字面量 px，令牌管不到 —— 片段里对这类地方
  都做了点名覆盖，并注明了。
- 这些片段只改**你自己浏览器的本地外观**，不影响服务端、不影响别人。

### ⚠️ 表面色要改 `--*-base`，不要改 `--surface` / `--sidebar`

「面板通透（毛玻璃）」开启时，`--surface` / `--surface-muted` / `--surface-strong` /
`--sidebar` 会被重新算成**带透明度的派生值**，来源是下面这 4 个基础令牌：

```
--surface-base  --surface-muted-base  --surface-strong-base  --sidebar-base
```

所以：**要换表面颜色，改 `--*-base`**。改 `--surface` 这类派生令牌的话，一开毛玻璃
就会被毛玻璃规则盖掉（毛玻璃规则权重 0,2,0，比 `:root` 的 0,1,0 高）。
`08-sidebar-tinted.css` 就是按这个写的 —— 它改的是 `--sidebar-base`。

（这个拆分是因为 CSS 变量不能自引用：要把 `--surface` 算成「原色的 78% 不透明」，
必须留一个没被覆盖过的原色给它引用。）


## 附：项目里的 4 个「死令牌」

`console/src/styles.css` 的 `:root` 里有 4 个变量**只有定义、没有任何 `var()` 读它们**：

```
--space-6  --space-7  --fs-title  --fs-display-3
```

覆盖它们**不会有任何效果**，所以上面的片段里没有出现。
这不是片段的问题，是项目令牌集里的小遗留 —— 要么补上引用，要么删掉定义，二者留一即可。

（另外 `--fs-display-2` 全项目只被引用 1 次，`--space-5` 1 次，属于「勉强在用」。）

## 这些片段是怎么校验过的

不是手写就交。`docs/appearance-presets/` 下 17 个文件都过了三道机器检查：

1. **语法**：用项目自带的 postcss 解析，17/17 通过，49 条规则全部合法。
2. **类名**：抽出片段里用到的全部类名，逐个到 `console/src/styles.css` 里核对是否存在，
   全部命中 —— 防的是「类名拼错 → 静默不生效 → 以为没效果」。
3. **变量**：抽出片段里覆盖的每个 `--*`，检查项目里是否真有 `var()` 读它，
   44 个覆盖全部有效（就是这一步揪出了上面那 4 个死令牌）。

`16` / `17` 这两份**额外**做了浏览器实测（Playwright，12 个路由 × 5 档透明度）：

| 布局 | **12/12 路由逐像素不变**（页高、行 top、面板高、分页位置、横向溢出） |
