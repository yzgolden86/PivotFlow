# P1 操作可达与可读性

用户已批准按既定路线连续推进，本阶段改善现有控制台的操作和阅读，不扩展网关数据面。

## 事实与取舍

当前共享 Modal 已有基本焦点限制和恢复；移动导航与 Key 健康窗口另有独立监听。嵌套搜索、菜单与弹窗会竞争 Escape/Tab，通用弹窗尚未统一滚动锁和背景隔离。全局搜索只有自动焦点及链接，资源失败没有反馈，上下键/Enter 不可用。站点、渠道和令牌的窄屏样式隐藏完整字段；令牌及权限选择列表没有渲染数量界限。站点健康排序在每次比较中扫描所有账号，站点/账号的“筛选下全部”实际只勾选本页。

采用共享浮层栈、现有 Portal 和原生按钮/输入框；维持默认表面、字体、主题、密度与 reduced-motion。分页比新虚拟列表更适合当前需要键盘定位、跨页选择和编辑的维护流程，且无需依赖、固定行高或额外滚动容器。详情直接使用已读取的安全字段，不发起模型调用、恢复秘密或配置写入。

## 交互契约

1. 共享 Modal、全局搜索和移动导航采用同一焦点生命周期。打开时保留已在内部的 autofocus，否则聚焦可说明上下文的容器；搜索聚焦搜索框，移动导航聚焦关闭按钮。Tab/Shift+Tab 不离开最上层模态。隐藏、disabled、负 tabIndex 和 inert 控件不参与遍历。
2. Escape 每次只关闭最上层浮层。菜单打开时先关菜单；嵌套搜索关闭后回到上层窗口及原控件，上层滚动锁仍在。最后一层关闭恢复先前 body 样式和可用的触发焦点；原触发元素已移除/禁用时使用上层或主要内容兜底。非最上层被程序关闭时不抢焦点。原生确认、异步取消、preview/apply、unknown/commit_unknown 均保留原有语义。
3. 菜单打开后可用上下方向键、Home/End、Enter/Space 与 Escape；Tab 关闭菜单并按正常顺序继续。定位、窗口边缘、缩放和 Portal 机制继续沿用。
4. 搜索以 combobox/listbox 描述当前候选。上下键改变候选，Enter 进入，IME 组合期间不执行。所有关闭方式清空查询并恢复焦点；导航完成聚焦主要内容。资源读取保留独立成功结果，失败显示资源类型和重试入口；关闭/重开或旧请求迟到不得覆盖新请求状态。结果最多显示 14 项并提示细化搜索，不静默隐瞒截断。
5. 分页提供总量、当前范围、上一页/下一页和有效的直接跳页；空集、删掉最后一页、搜索与页容量变化都保持有效页码。跳页 Enter 不能提交外层令牌表单。320–390px 中分页可换行。
6. 令牌主列表每页默认 50、可选 100；令牌权限中的模型与渠道选择每页 50；Key 健康每页 50。选择跨页/搜索保留，计数明确。权限“全选”明确为已加载清单，批量 Key 检测仍按当前筛选取最多 20 个，分页不改变检测目标和停止行为。搜索失败/无匹配与没有资源分别表达。
7. 站点与账号的本页全选名称与实际范围一致；已选对象在筛选外时显示数量，并提供清空入口。筛选和翻页不得偷偷丢失选择，也不得把批量目标扩展为未选择对象。站点账号分组与健康数按一次遍历构建，排序/渲染共用。
8. 站点、渠道、令牌均有始终可聚焦的“详情”入口。详情展示完整名称、地址/协议、状态/时间、路由和范围/限制等已持有的字段；未知保持未知、本地费用保留估算/未对账含义。令牌详情仅显示提示，不请求或展示完整密钥。
9. 320px 与 390px、深浅主题、长名称/URL/模型、短视口和桌面 200% 等效缩放可阅读和关闭。弹窗标题、详情值、错误信息和分页换行，关键控制至少保持现有命中尺寸；共享可见焦点包含输入、选择、textarea 和 summary。系统设置分类使用规范的方向键与标题/面板关联。

## 验证与预算

合成管理 API 拦截覆盖实际 React 页面；禁止真实上游、生产登录、生产数据库和 WebDAV。浏览器导航期限 30 秒、动作断言 5 秒；静态服务器有所有权、readiness 与 finally 清理。截图仅可视视口 JPEG。真实屏幕阅读器与手机软键盘的体验不由 Chromium 合成检查替代。

先记录当前构建的资源数、gzip 大小、各路由解压大小及大列表 DOM/操作耗时，再比较最终构建。沿用原 400,000 字节会话 gzip、150,000 字节单路由 gzip、450,000 字节单路由解压预算；旧 45 个请求上限需同时报告本阶段起点是否已因前几阶段超出，不擅自调高。保持现有 reduced-motion 和玻璃表面策略，不新增每行 blur。重型 Go/lint/浏览器验证串行，Vite 不与 Go embed 构建重叠。
