# 配置导入与渠道同步差异预览

日期：2026-11-21。承接已批准的路线顺序，由本轮作出以下实现选择。

## 目标与边界

JSON 备份导入、WebDAV 恢复和渠道页站点同步必须先显示将写入的条目，确认后应用同一份快照。新增、更新、无变化、保留、冲突、停用分别计数；每项有稳定位置、对象类型、字段名和安全的说明。凭证、请求规则、代理地址及设置值不输出到差异；仅显示字段是否变化。CSV 与 OAuth 专用导入入口保持本轮范围之外。

## 方案

后端保存最多 16 个、已保留内容编码后合计最多 64 MiB、10 分钟有效的内存预览；这是快照和公开结果的内容预算，Go 对象与请求临时副本另有开销。随机 ID 指向固定的导入文档或上游快照，客户端确认仅发送 ID。应用请求串行领取预览；成功后再次确认返回同一结果，不重复写入或触发重启。失效、冲突或已变化的本地配置拒绝应用。应用完成后结果再保留 10 分钟，支持临近过期确认后的响应恢复；关闭或替换预览可用 DELETE 释放记录，正在应用的记录不能删除。预览不持久化秘密、不写业务配置；站点预览允许凭证续期与任务状态更新，不能创建或覆盖渠道。

备份使用同一规划器执行预检和应用：站点按规范化地址匹配，同名不同地址为冲突；账号按映射后的站点和标签匹配；渠道按名称匹配，源 ID 只用于引用重映射；令牌按散列匹配。重复身份、缺少引用、无效配置、认证类型变化等在任何写入前列出。现有自动投影渠道由备份更新时标记为手动，防止后续自动同步回滚恢复内容。未知及容器管理的设置保留，历史不可恢复令牌跳过。补齐令牌协议限制的导出/恢复，避免权限扩大。

备份应用在主数据库配置事务中重新比较指纹并执行全部更改；确定的条目写入失败回滚整个备份。提交阶段无法确认结果时显示 unknown 并禁止自动重试；浏览器未收到响应时使用 GET 读取服务端结果。错误只带条目位置和稳定代码。日志、统计及已有令牌已用额度不在恢复范围。事务提交后才刷新运行时缓存；副本同步失败显示已提交和缓存警告，不报告回滚。系统设置确有变化时才提示并由首次成功应用触发重启。应用不因浏览器断线取消，受两分钟执行时限和服务生命周期控制，服务关闭时取消并等待已登记应用。

站点预览沿用既有队列、账号租约、站点请求预算及取消语义，分别读取每把上游 Key 的模型、协议和分组。展示每个投影的变更；手动所有权默认保留，移除的 Key 仅停用旧渠道，保留历史。一个账号内采用事务应用固定快照；不同账号逐项报告结果。部分发现失败时不推断其他 Key 已被删除。前端选择变化、文件变化、关闭弹窗时使旧请求失效；取消/超时应用显示结果待确认，不猜测写入失败。

## 界面

沿用现有紧凑卡片、弹窗、主题及响应式布局。共用差异组件含计数、筛选、搜索、逐条字段和保留原因。备份先“预览导入”，再“确认应用”；WebDAV 先下载到服务端预览，确认时不重新下载。同步弹窗先选择账号生成预览，再确认；提供完成结果、失败项位置和重新预览入口。

## 验证

覆盖无写入预览、秘密不回显、重复身份、引用丢失、权限保留、陈旧预览、重复应用、事务回滚、手动所有权、部分上游失败、旧 Key 停用及前端迟到响应。运行 Go/TypeScript 测试、lint、构建及合成浏览器检查。无真实账号操作，无生产进程运行，无提交、推送或发布；不宣称验证真实 MySQL/Postgres 或 race detector。
