## 实现范围

默认关闭、当前进程内存、客户端 `use`／`refresh`／`bypass` 显式选择。首期为原生 OpenAI Chat Completions 与 Anthropic Messages 的非流式、显式 temperature=0、单候选纯文本；精确令牌／协议／路径／原正文／语义头隔离。工具、Cookie 会话、未知字段、媒体、Responses／WebSocket、实际协议转换、OAuth／AnyRouter 和语义改写绕过。

LRU／TTL、条目与单条／总正文上限、在途捕获独立上限和 4096 活跃键登记；全局失效及每键填充代际防清空／刷新旧结果回填。命中仍走权限、全局／令牌并发、费用和可靠结算准入，只读候选不推进路由游标；完整写出后记一次幂等成功结算，新上游 tokens/cost=0。写失败／取消不记成功；历史零真实上游尝试、不造渠道日志。

设置、管理员只读快照与确认清空、运行健康可选观察、固定历史字段及 SQLite／MySQL／PostgreSQL 增量迁移已连接。前端区分草稿与进程策略，旧快照不用当前状态字样，固定 DTO／原因及容量／时间关系严格校验，8 秒超时／迟到／卸载保护；清空未知结果不自动重试。使用说明见[请求缓存](../../request-cache.md)。
