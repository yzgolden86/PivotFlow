## RED 与 GREEN

- 焦点初次 RED 2/8，随后说明提示的 Escape 回归复现父层被误关闭。共享栈统一顶层事件、滚动锁和 inert，并移除 Key 健康与移动导航的重复 trap。最终焦点组包含 13 个场景。
- 菜单焦点的浏览器问题由减少运动规则中的 `.01ms` 过渡引起：默认 `transition-property: all` 为未声明动画的菜单制造了 visibility 过渡。样式覆盖证明根因，最终两个减少运动规则改为 `0s`；无效的帧延迟/定位实验已撤销。
- 搜索 RED 2/6，候选键盘、失败反馈和截断说明实际失败，修复后通过。一次严格定位器把站点及其账号的多个有效结果误认为单个，改为断言站点链接；没有为该测试问题修改产品。
- 大列表 RED 复现令牌/权限/Key 渲染未受限、缺少直接跳页和不清楚的选择范围。分页、精确选择及末页删除修复后，151 令牌、2,000 模型、120 渠道和 120 Key 的场景通过。
- 详情 RED 1/10：八组布局没有详情入口，设置分类没有方向键。第一次 GREEN 8/10，720px 渠道页的筛选 select 实际延伸到 x=790；局部换行修复了溢出。新加的短搜索测试错误地要求两块错误提示，产品本来就在一块状态区说明两类失败；改为分别核对渠道和模型名称。
- 预算 RED 在初次详情构建后实际测得 51 个请求，原定 45 个上限失败。共享图标打包后为 32 个，继续保留页面动态导入和原预载时机。

`final-ui-verified/result.json` 记录初次完整 37/37。审查前再加短弹窗焦点可见性，`focus-visible-red` 实际 0/1：Shift+Tab 聚焦保存按钮却留在视口外。只让键盘跳转允许浏览器滚动目标、保留关闭恢复的页面位置后，`review-ready-ui/result.json` 38/38：焦点 13、搜索 6、列表 6、详情 12、预算 1，未预期事件为 0、服务器关闭。Node/两套 TS/Vite 再次通过，Go 嵌入构建更新到 `worktree-review-ready-go-result.json`；原始失败与成功证据不改写。

## 浏览器边界

测试只服务 `web/console` 和品牌 SVG 的白名单静态文件，所有管理与会话 API 合成响应，全部外部源阻止访问。导航期限 30 秒、断言 5 秒；服务器、线程、浏览器和上下文均在 finally 清理，空用例组不能算通过。图片只截可见视口 JPEG。

覆盖 320×740、390×844、1440×900 和 720×450 的深浅主题，320×450 的短窗口，长名称/URL/模型、标题与关闭、完整字段、无横向裁剪及焦点返回。720×450 是桌面 200% 等效布局，未实际操作浏览器缩放。代表性的 320px 浅色令牌及 720px 深色渠道图已经人工查看。真实屏幕阅读器、移动软键盘与真实客户端仍需部署环境确认。
