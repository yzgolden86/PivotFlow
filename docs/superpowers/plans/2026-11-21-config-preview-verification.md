## 已验证行为

服务端固定输入快照，确认只提交预览 ID。差异展示新增、更新、无变化、保留、冲突和停用，并列出字段、保留原因及安全条目位置；不返回秘密值、配置指纹或原始 SQL/Provider 错误。旧无预览恢复接口返回 428 `preview_required`。

预览最多 16 条，保留内容采用 64 MiB 编码预算、10 分钟有效期，Go 堆和请求临时副本另有开销。终态再保留 10 分钟，关闭和替换预览可主动删除，正在应用时不能删除。并发重复应用只执行一次，重复 HTTP 确认也只触发一次必要重启。服务关闭取消并等待应用；应用不因浏览器断线取消，最长执行两分钟。

备份整份配置事务、站点同步按账号事务。确定的写入错误回滚；本地配置或路由资格变化使旧预览失效。提交结果不明与浏览器观察中断分别处理，前者禁止重试，后者通过 GET 恢复。主库已提交但副本或令牌权限重载失败时明确显示警告。

同步默认保留手动所有权，已确认移除的上游 Key 对应渠道只停用并保留历史；发现不完整时不推断移除。同一密钥的最新健康和冷却不被旧快照覆盖，密钥轮换清空旧观测，保留人工停用、模型范围、备注、策略和倍率。配置导入改变自动渠道时展示其转为手动管理，账号级联停用也单独显示。

备份对象身份按实际目标匹配，源 ID 只用于引用重映射。令牌的模型、协议和渠道限制保留；缺少引用列冲突，旧备份未提供协议限制时保留目标已有限制。已用额度、日志和结算回执不通过 JSON 恢复。

## 独立复核及修复

复核比较本阶段与当前主目录基线，不把此前未提交改动重复归入本阶段。逐项确认后修复的问题如下：

1. 无效认证类型与协议模式在二次归一后误通过校验。失败用例覆盖错误类型和模式，现写入前列为冲突。
2. 账号停用的渠道级联与自动渠道恢复后的手动所有权未完整展示。预览增加派生停用项及管理归属字段；账号路由资格变化进入指纹，防止应用时产生新增的隐藏停用。
3. 密钥轮换时恢复函数写回旧密钥；排除易变字段后还可能覆盖新健康与冷却。现凭据取固定上游快照，运行观测取应用事务内当前状态，轮换后清空旧观测。备份不导入旧健康状态。
4. `omitempty` 字段被清空时，差异只遍历导入后存在的键，漏报代理、请求规则、WebSocket 和可用时间清除。现比较前后键的并集；10 个实际恢复回归覆盖单独清空和清空同时修改另一字段。
5. 混合事务的镜像与普通更新、令牌撤销可交错，旧快照覆盖较新的缓存。实例内共享配置锁覆盖主库写入及镜像发布，渠道与 Key 从同一个主库事务快照读取；新日志健康按密钥及观察时间保留。令牌权限热重载从主库读取，并串行读取/发布，副本失败不复活旧权限。
6. 令牌重载错误原被忽略。结果继续表示配置已提交，并附单独或组合警告；不把运行态失败报告为主库回滚，也不返回原始存储错误。
7. 服务关闭未等待预览应用、临近过期确认后无结果可查、回调 panic 留在应用中、重复确认触发多次重启。现登记服务生命周期、续期终态结果、panic 变为不可重试的 unknown，并只由首次成功调用触发重启。
8. WebDAV 预览可能回显存储/解密错误。现只返回允许的稳定错误码；页面把安全代码和条目位置译为中文。
9. 文件移除后的迟到预览、替换批次的容量泄漏及应用/复查双重断线。现使旧请求失效并释放可丢弃记录，读取有八秒上限，未知结果禁用应用并保留手动复查按钮。

独立复核摘要及处理记录见外置 `independent-review.md`。完整测试和最终构建覆盖修复后的文件；初次失败及后续成功均分别保留。

最终冻结复核未留下 Critical 或 Important 阻塞。关于 Key 冷却仍可能覆盖的末轮报告，经按文件散列和完整方法体复核后撤回：bump、set、reset 和 reset-all 均已持同一配置锁直至主库与缓存写入完成，现有运行态排序回归覆盖这些入口，无需再改变合并策略。读取在写入尚未完成时仍可观察到旧副本值；跨实例即时一致仍属于下文限制。

## 限制与下一项

本机验证使用临时 SQLite 和合成 Provider/Chromium API。未连接真实 MySQL/PostgreSQL，未运行 race detector，未使用生产账号、执行签到或启动生产程序。配置发布排序仅限当前 `HybridStore` 实例；多个服务实例共用主库时，不保证各自 SQLite 副本即时一致，也不提供跨进程发布顺序。部署中的主库连接、故障注入和恢复仍需实际环境验收。

本阶段不提交、推送、发布或部署。下一项按既定路线推进 **P1 费用来源与数据语义**：区分站点价目估算、本地公开价估算、未知与零价，以及实际账单确认，统一日志和数据面板的解释。
